# Architecture Website

## 📌 Project Overview

The **Architecture Website** is a simple responsive website designed to showcase architectural projects, architects, and provide a contact section for visitors.

The website is created using **HTML and W3.CSS**. It contains a clean navigation bar with links to the Projects, About, and Contact sections.

## ✨ Features

* Responsive navigation bar
* Architecture-themed homepage
* Projects gallery
* About section
* Architect profiles
* Contact form
* Responsive layout using W3.CSS
* Footer section

## 🛠️ Technologies Used

* HTML5
* W3.CSS
* External images

## 🏗️ Website Sections

### 1. Home

The homepage contains a large architecture image with the website title **SSA Architects**.

### 2. Projects

The Projects section displays different architectural projects such as:

* Summer House
* Brick House
* Renovated House
* Barn House
* Winter House
* Mansion
* Haveli
* Tower

### 3. About

The About section introduces the architectural theme of the website and presents information about different architects.

### 4. Architects

The website contains profiles for architects including Sunita Kohli, Ar. Samira Rathod, Ar. Shubhra Raje, and Ar. Amritha Ballal.

### 5. Contact

A contact form is provided where visitors can enter their:

* Name
* Email
* Subject
* Comment

and submit a message.

## ▶️ How to Run

1. Download or clone this project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your web browser.
