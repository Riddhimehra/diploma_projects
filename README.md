# Diploma Projects

A collection of projects developed during my Diploma in Computer Engineering.
This repository contains projects created using Python, Java, C, HTML/CSS, PHP, SQL, and machine learning technologies.

## Projects
1. Architecture Website
Technologies: HTML, CSS, PHP, SQL
A website for exploring architecture services and managing related information.

2. Blackjack Game
Technology: Python
A console-based Blackjack game where the player competes against the computer.

3. Computer Networking Chat
Technology: Python
A simple chat application demonstrating computer networking and client-server communication.

4. Employee Management System
Technology: C
A basic system for storing and managing employee records.

5. Heart Disease Prediction
Technologies: Python, Machine Learning
A machine learning project that predicts the possibility of heart disease using health-related data.

6. Student Record Management System
Technology: Java
A system for adding, viewing, searching, and managing student records.

7. Task Planner Chatbot
Technologies: Python, AI
A task-planning chatbot that helps users organize and manage their tasks.

8. Voting Machine
Technology: C
A simple voting machine program for conducting and counting votes.
