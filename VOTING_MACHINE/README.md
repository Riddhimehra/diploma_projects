# Voting Machine

A simple console-based Voting Machine project developed in C.

## Description

This project allows users to enter a candidate's name and assign voting points to the selected candidate. The program stores the voting results in a text file so that the previous results can be loaded when the program is run again.

## Features

- Displays available candidates
- Allows users to enter candidate names
- Adds voting points to candidates
- Displays voting results
- Saves results in a text file
- Loads previous results when the program starts

## Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- String Handling

## How to Run

Compile the program using a C compiler:

gcc voting_machine.c -o voting_machine

Then run:

./voting_machine

## Output

The program displays the voting results for all candidates after the user enters the candidate name and number of points.
